# GPTAPI
推荐好用的GPT和ClaudeAPI使用
推荐地址：https://api-top.com/sign-up?aff=QeEF
可以支持使用GPT、Claude、Gemini以及国内模型

1.CC Switch 下载：
https://github.com/farion1231/cc-switch/releases

国内下载：
https://gitcode.com/YujinDawnlight/cc-switch-download

2.创建 Top API API 密钥
登录 Top API，打开「API 密钥」并创建密钥。填写名称，选择自动分组或需要的分组，创建后复制完整密钥。

3.从 Top API 导入 CC Switch
打开密钥右侧菜单，选择「导入到 CCS」。应用选择 Codex 或 Claude Code，再选择密钥支持的模型，点击「打开 CC Switch」。

网站也有教程：
https://api-top.com/codex-config
